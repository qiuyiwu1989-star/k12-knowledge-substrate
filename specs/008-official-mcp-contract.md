# 008 官方 MCP 定义与 Agent 读取契约

用户要求参考深脑 MCP 定义面向多应用的 K12 官方接口。本轮交付 v0.1 候选规范、Agent 指南、机器可读工具目录与验收场景；不以规范文件冒充已实现接口，不改变现有五工具运行行为，不部署远程端点。

复用 mcp/server.mjs、present.mjs、workbench/core.mjs 的现有能力；新增方案明确差距、版本、证据与教育推断边界。参考深脑两份 2026-09-06 接入需求与客户回复，它们属于设计及验收资料，本轮未实测深脑远程 MCP。

验收：目录 JSON 可解析，工具名唯一；P0/P1 明确；每工具注明何时用、何时不用、输入、返回、边界；Agent 可直接按 ID 读取；返回标明未知、截断、来源与状态；规划工具不出现在现有 tools/list 中。

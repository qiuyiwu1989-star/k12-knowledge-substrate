应用共用的能力坐标

一次定义，三种接入方式。

网页、HTTP 和本地 MCP 使用同一套小学科学映射核心。返回的是待确认候选，映射判断保留在应用层，不回写课标底座。

HTTP · 直接映射任务

公开只读接口，不保存提交的任务内容。目标年级 1–6，每次 1–8 个任务，每项 4–400 字。每分钟最多 20 次写方法请求；忙碌时返回 503，可稍后重试。

curl https://k12.yongle.school/workbench/api/map \
  -H 'Content-Type: application/json' \
  -d '{
    "title": "溶解实验室",
    "grade": 3,
    "tasks": [{
      "id": "experiment-1",
      "text": "通过对比实验，说明搅拌对食盐在水中溶解快慢的影响。"
    }]
  }'
接口用途
GET /workbench/api/meta范围、年级数量、数据版本和指纹
GET /workbench/api/catalog?grade=3&q=溶解能力检索；支持 offset、limit 分页
POST /workbench/api/map按任务召回候选
POST /workbench/api/validate核验映射文件，返回规范化数据；不保存

MCP · 给你的 AI 工具使用

从开发分支取得仓库，需要 Node.js 与 Python 3。现有 MCP 服务新增 map_science_tasks，原有查询工具继续可用。当前是本地 stdio 接入，不是可粘贴到远程 MCP 配置中的 URL。

git clone --depth 1 --branch feat/primary-science-mapping-workbench \
  https://github.com/qiuyiwu1989-star/k12-knowledge-substrate.git

{
  "mcpServers": {
    "k12-substrate": {
      "command": "node",
      "args": ["/你的绝对路径/k12-knowledge-substrate/mcp/server.mjs"],
      "env": { "K12_USAGE": "0" }
    }
  }
}

调用 map_science_tasks，参数与上面的 HTTP 请求相同。每条候选附课标来源、适用年级、复核来源和粒度提醒，结果同时提供 text 与 structuredContent。

映射记录的含义

pending 待确认、confirmed 应用映射已确认、rejected 已排除。关系为 requires 前置要求、trains 主要训练、observes 可观察表现。确认需任务原文摘录与具体理由。

保留 datasetVersion 与 datasetFingerprint。导出文件可在工作台导入并再次核验。工作台保存属于浏览器会话；第三方项目持久化请放在调用方自己的库中。

现在怎么用

当前支持在自己的电脑或应用运行环境中启动 MCP。此页面是使用说明，不是远程 MCP 接口地址。远程 MCP、知识与课程联合查询仍在规划中。

QUICK START

三步，接入你的 AI 工具。

准备 Git、Node.js 22.13 或更高版本、Python 3，以及支持本地 stdio 的 MCP 客户端。无需安装 npm 依赖；node 与 python3 需要在客户端进程的 PATH 中。

1

取得可复现的版本

下面固定到本页核验的提交，避免开发分支后续变化影响接入。

终端
git clone --branch audit/release-readiness-20260906 \
  https://github.com/qiuyiwu1989-star/k12-knowledge-substrate.git
cd k12-knowledge-substrate
git checkout d80cb1a
npm run mcp-test

测试会启动真实 MCP 进程并检查通信。手动执行 node mcp/server.mjs 后等待输入是正常行为。

2

添加本地 MCP 配置

以下适用于接受 mcpServers JSON 配置的客户端。替换成仓库在你机器上的绝对路径；其他客户端按其格式填写同样的 command、args 和 env。

客户端 MCP 配置
{
  "mcpServers": {
    "k12-substrate": {
      "command": "node",
      "args": ["/你的绝对路径/k12-knowledge-substrate/mcp/server.mjs"],
      "env": { "K12_USAGE": "0" }
    }
  }
}

保存后让客户端重新加载 MCP。若提示找不到 node，填写 node 可执行文件的绝对路径；同时确保 Python 3 可被该进程找到。

3

把一个真实任务交给 Agent

请用 K12 MCP，为三年级“通过对比实验说明搅拌对食盐溶解快慢的影响”查找能力候选。展开关键候选的课标来源，说明哪些是推导改写，以及还需要什么证据才能评价实验能力。

客户端应能发现下方 5 个工具。先看候选，再展开依据；返回映射不等于学生已经掌握。

AVAILABLE NOW

当前可以调用的 5 个工具

search_anchors

根据教学文本寻找能力候选，建议指定学科和年级。

get_anchor

按 ID 查看能力表述、来源片段、证据描述和关联。

get_prerequisites

查看已有依赖链。关系仍需核验，hard 标签不能直接作为学习门槛。

list_slice

查看学科、学段或年级分片；读取分片需要本地已有构建产物。

map_science_tasks

映射小学科学具体任务，支持 1–6 年级，返回待确认候选。

开发者：查看 map_science_tasks 调用参数

这是工具 arguments，不是完整 JSON-RPC 请求。每次 1–8 个任务，任务文本每项 4–400 字。

工具参数
{
  "title": "溶解实验室",
  "grade": 3,
  "tasks": [{
    "id": "experiment-1",
    "text": "通过对比实验说明搅拌对食盐在水中溶解快慢的影响。"
  }]
}

READ THE RESULT

拿到结果后，先看这四件事。

01

候选是什么

能力表述与稳定 ID。文本相似只用于召回，需要结合任务核对。

02

依据在哪里

课标来源、页码和保留的片段。推导改写与课标表述分开看。

03

适用到哪里

年级范围、任务条件和粒度提醒。宽范围不等于精确年级要求。

04

还有什么未知

AI 审阅不等于教师审定。应用覆盖、评价设计与学生掌握分别判断。

常见问题与使用边界

能否把本页面 URL 粘贴到远程 MCP 配置？

不能。当前提供本地 stdio 服务。网页工作台的 HTTP API 也不是远程 MCP endpoint。

list_slice 提示分片未生成？

它读取本地构建产物；尚未构建时先用 search_anchors 或 get_anchor。完整构建方式见仓库 deploy/README.md。

是否会修改公共图谱？

MCP 查询与映射不会回写课标能力底座。应用的映射判断由调用方保存；示例配置关闭本地使用计数。

知识体系和课程查询现在能用吗？

尚未接入当前 MCP。可以先浏览知识体系页面，联合查询能力以未来实际工具清单为准。

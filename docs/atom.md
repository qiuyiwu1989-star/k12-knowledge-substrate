# 原子能力点：详情页要哪些维度，怎么审

## 先解决「原子」这两个字，再谈字段

诗歌库的原子是**一首诗** —— 那是天然给定的，不用论证。
我们的原子不是。「能计算两位数乘三位数」和
「能计算两位数乘三位数和三位数除以两位数」，哪个是一条？

**判据只能有一个，而且必须可判定：**

> 如果对同一个孩子，可能出现「A 会、B 不会」，那 A 和 B 就是两个原子。

这条判据不是发明的，它就是可判定性判据往下推一层：一个锚点只承载一个二值结论，
承载两个就意味着档案里会出现「半会」，而「半会」不是一个能记录的状态。

### 实测：28% 的锚点不原子

| | 条数 |
|---|---:|
| ✅ 单一判定点 | 1,548 |
| 「和」连接两个对象 | 349 |
| ≥3 项并列 | 91 |
| 「并」连接两个动作 | 49 |
| 逗号后另起一条要求 | 37 |
| 多种复合叠加 | 87 |

样本一看就明白：

```
能认、读、写万以内的数          孩子可能读得出 3000 却写不出来 → 三个原子
会计算平行四边形、三角形、梯形的面积   三角形会、梯形不会是常态 → 三个原子
能说出直角、锐角、钝角的特征        一个概念族，一次判定 → 一个原子
```

### 拆分不等于改写 —— 界线在这里

这个项目立过规矩：**高中那条线零模型调用、不改一个字**，因为
「只要允许改写，就存在一条比忠实更省力的过闸路径」（见 [rewrite.md](rewrite.md)）。
那拆分算不算改写？

**不算，只要拆出来的每一条都是原句的子串重组，不新增一个字。**

```
✅ 能认、读、写万以内的数 → 能认万以内的数 ／ 能读万以内的数 ／ 能写万以内的数
❌ 能说出略读的目的是粗知文章大意          ← 原文没有「目的是」，这是编的
```

这条界线是机器可查的，用的是和 `make_assessment.py` 同一道闸：
**拆出来的实词必须全部来自原句**。多一个词就拒绝。

拆出来的子条与母条之间是**组成关系，不是先修关系**。
现在 `edges/` 只有先修边，需要新增一种边类型 `composes`，
否则「会写 3000」会被表达成「会读 3000」的后继，那是错的 —— 它们没有先后。

## 维度表：每一维必须挂在一个可查的体系上

这是从诗歌库抄来的唯一一条方法论。那边每首诗的维度都挂在外部封闭体系上：
色彩挂郭浩《中国传统色》384 色、意象挂词表、典故挂出处。
挂不上的（「这首诗美不美」）就不标。

**同一条规矩在这里的形式：**

> 一个维度能不能机器打标，取决于它有没有**闭合词表**加**可判定的归属判据**。
> 两样缺一，宁可留空。

这条不是空话，它已经杀掉过我们自己的东西：学科核心素养可以打
（2022/2017 课标逐科印着清单，闭合），而《中国学生发展核心素养》六大项
打不了 —— 它在育人目标层，比一条具体断言高两个抽象级，
「能判断一元二次方程实根个数」到底在长科学精神还是学会学习，**没有可判定答案**
（见 `mappings/crosscutting.json` 的 `coreCompetencyStatus`）。

### 一 · 身份

| 维度 | 权威来源 | 现状 |
|---|---|---|
| `id` | 自编码，无语义、永不复用 | 100% |
| `statement` / `verb` / `object` | 课标原文 | 100% |
| `discipline` / `strand` / `topic` | 课标目录层级 | 100 / 76 / 50% |
| `courseType` 必修·选择性必修·选修 | 高中课程方案 | 高中 100% |

### 二 · 认知坐标

| 维度 | 权威来源 | 现状 |
|---|---|---|
| `cognitive` 了解／理解／掌握／运用 | **课标自己的行为动词分级**（国内官方表述） | 100% |
| `bloom` 记忆／理解／应用／分析／评价／创造 | Anderson & Krathwohl 2001《修订版布卢姆分类学》认知过程维度 | **没有** |
| `type` 知识类型 | **自造的六值**（CONCEPTUAL／PROCEDURAL／REPRESENTATIONAL／LANGUAGE／KNOWLEDGE／META） | 100%，但不可比 |
| `literacy` 学科核心素养 | 课标逐科印着，闭合词表 | 100% |

`type` 这一维现在是我们自造的，外部没法对齐。A&K 的知识维度是
事实性／概念性／程序性／元认知四类，是公开的、被广泛引用的框架。
**建议加一个到 A&K 四类的映射字段，保留自造值不动** —— 自造值有它的用处
（LANGUAGE、REPRESENTATIONAL 是语文外语真实需要的区分），但可比性要靠映射拿。
加 `bloom` 同理：课标四级是权威，Bloom 六级是跨体系的通用坐标，两套并存、互不覆盖。

### 三 · 学习坐标

| 维度 | 权威来源 | 现状 |
|---|---|---|
| `stageHint` 学段 | 课标学段划分，**按学科取**（艺术是 1-2／3-5／6-7／8-9） | 100% |
| 前置边 | 知识空间理论（Doignon & Falmagne, *Knowledge Spaces*）—— 先修结构是可被响应数据检验的 | 67% 有前置 |
| 后继边 | 同上 | 44% |
| 孤立度 | —— | **513 条既无前置也无后继**，详情页必须诚实显示 |

先修边现在全是 `soft` + `llm-proposed`。知识空间理论的价值恰恰在于
**先修关系是可证伪的**：如果大量孩子在没掌握 A 的情况下掌握了 B，
那条 A→B 的边就是错的。这需要 L3 的聚合数据，现在还没有，
但字段结构要为它留好位置。

### 四 · 判定（现在最弱的一组）

| 维度 | 权威来源 | 现状 |
|---|---|---|
| `evidence` 掌握证据 | 我们自己写的行为描述 | 100%，但**其中 860 条（全库 40%）是同义反复模板** |
| `assessment` 家长问句 | 机械生成，实词不得超出断言与证据 | 95% |
| **`mastery` 掌握判据** | 掌握学习（Bloom 1968）：要说清**几次、什么条件、保持多久** | **没有** |
| **`variations` 变式空间** | 变式教学（青浦实验一脉）：同一能力的题目变式边界决定「会」的边界 | **没有** |
| **`misconceptions` 典型错误** | 学科迷思概念研究（如物理的 Force Concept Inventory, Hestenes 1992） | **没有** |

这三样是详情页的真正价值所在。而且这一组比想象的更空 ——
2026-08-20 查出 **860 条的 evidence 是「能在X课堂或作业情境中完成：<断言原文>」**，
把断言又说了一遍（详见 [disputed.md](disputed.md)）。

就算是写得认真的那些，也只说「学生能正确指出数字 123456789 中数字 5 在万位」，
**没说做对几道算会、隔一个月还算不算会**。
一个判不出「会/不会」边界的判定证据，等于把判断又推回给人。

`misconceptions` 尤其值钱：判「会」看行为，判「不会」看错法。
「计算 300-198 时用竖式退位出错」和「不知道可以凑整」是完全不同的两种不会。

**但这三样都会引入我们自己的判断，而不是课标转述。** 所以它们必须走
`capability-rewrite` 那一层的待遇：单独标来源、单独统计、能被单独撤掉、
**永远够不到 `auto-confirmed`**。

### 五 · 横切

| 维度 | 权威来源 | 现状 |
|---|---|---|
| `crosscutting` | NGSS 七个跨学科概念，闭合 | 50%，文科一律留空（词表不适用，宁可空着） |
| `practice` | NGSS 八项科学与工程实践，闭合 | 66% |
| 易混锚点 | 同学科下 `(verb, object)` 相近但不同的条目 | **没有**，可机械算 |

### 六 · 溯源与可信度

| 维度 | 现状 |
|---|---|
| `provenance.srcText` / `srcPage` / `srcStage` | 93 / 100 / 20% |
| `reviewStatus` + `aiIssues` | 100%，其中 112 条 disputed 带具体异议 |
| `evidenceSource` | 100%，`capability-rewrite` 那 217 条一眼可辨 |
| `independentCheck` 对抗验证 | 21% |

**详情页必须把可信度放在显眼位置，不能藏在角落。**
2,161 条里只有 388 条可用、0 条有教师签字。一个把 `llm-proposed`
和 `expert-confirmed` 画成一样的详情页，是在骗读者。

### 七 · 使用数据（有位置，但现在必须是空的）

被多少档案引用、通过率、平均掌握年龄 —— 这些是校验先修边对错的唯一手段。
**但 L3 永不进仓库**，只能以聚合形式回流，且要有最小样本量门槛。
现在一条都没有，字段先不建，免得建了就有人往里填假数。

## 审核标准：每一维一条判据

现有的 [五关审核标准](review-standard.md) 判的是**这条锚点该不该存在**。
详情页多出来的维度需要各自的判据，否则「审核通过」这句话没有定义。

| 维度 | 通过判据 | 拒绝的典型 |
|---|---|---|
| 原子性 | 想不出「A 会 B 不会」的情形 | 能认、读、写万以内的数 |
| 拆分合法性 | 拆出的实词全部来自原句 | 引入了原文没有的词 |
| `cognitive` | 能在课标原句里指出定级所依据的那个动词 | 靠语感定级 |
| `bloom` / A&K 映射 | 映射表是公开的、逐条可查的 | 模型现场判断 |
| `literacy` | 取值在该学科课标印的清单内 | 清单外的自造词 |
| `stageHint` | 与 `srcStage` 一致，或有明确的冲突记录 | 比课标窄（发明精度） |
| 前置边 | 能说出「不会 A 就做不了 B 的哪一步」 | 「A 在前面学」 |
| `mastery` | 写明次数、条件、保持期，三者缺一不可 | 「熟练掌握」 |
| `variations` | 至少两个变式，且能说明哪一个变式一旦不会就算不会 | 同一题换数字 |
| `misconceptions` | 是**学生真实会犯**的错，不是「没学会」的同义反复 | 「不理解概念」 |
| `crosscutting` | 说得出这条和该概念的哪一条具体联系 | 硬凑一个标签 |

### 一条元规矩，管住上面所有维度

> **没有闭合词表加可判定归属判据的维度，不许机器打标。**

这条已经用两次代价换来了：一次是核心素养打标失败两轮（先是
「背诵《敕勒歌》→ 科学精神」这种硬凑，加了一致性约束之后又坍缩成
所有学科都是人文底蕴）；一次是 topic 想按相似度回填，
结果义务教育的「知道甲骨文是已知最早的汉字」匹上了高中历史的
「史料及搜集、运用史料的原则与方法」。

**两次都是同一个错：拿一个没有可判定答案的问题去问模型，
模型一定会给答案，而那个答案一定是编的。**

## 落地顺序

1. **原子性审计** —— 613 条复合锚点逐条判，可机械拆的机械拆，
   需要判断的进队列。新增 `composes` 边类型。**零模型调用。**
2. **详情页** —— 用现有字段先做出来。现有字段已经够撑一个诚实的详情页，
   而且它会立刻暴露哪些维度是空的 —— 这比先补字段再做页面靠谱。
3. **A&K / Bloom 映射** —— 一次性的映射表，逐条可查，不是模型判断。
4. **mastery / variations / misconceptions** —— 三样都要引入我们自己的
   教育判断，按 `capability-rewrite` 的六条闸办：单独标、单独统计、
   永远够不到 auto-confirmed、能被一条命令撤掉。

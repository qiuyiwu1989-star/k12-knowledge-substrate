留下来的方法

这些下次还用

改信息流，不改措辞

两段式重标：先让模型写「不会会怎样」，不告诉它有分类任务，再用另一次调用只看失败表征去分类。对抗验证、独立校验器同理 —— 验证方不共享被验证方的内部状态。

立不变式，不逐个审

同一天撞到三个「注释和代码说反」之后的结论：逐个审工具审不过来，立一条「记录只增不减」才拦得住下一个还没写出来的工具。

闸要先证明抓得住

每道新闸接进 CI 前先伪造一次违规。第一次测 no-id-reuse 时测试用例本身造错了 —— 不伪造就发现不了。

宁可少建，不要建错

跨学科边命中率从提议的 5.4% 掉到最终 0.51%，那是这条路上第一次真正施加判据。一条错的 hard 边会让产品告诉家长一件假的事。

子 Agent 只写临时区

并行时一律只许写 tools/out/，文件名带组前缀，主进程统一核验入库。这一轮六个 Agent 零冲突；上一轮两个都叫 refill.py，互相覆盖。

归属要记原话

「这条决定是谁做的」只认原话。学业质量那条口径先记成「我的判断」，等到你说「确认」才改成你的 —— 行为不等于授权。

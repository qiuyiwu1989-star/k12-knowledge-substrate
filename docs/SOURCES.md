## 一、官方课标：能拿到，但全是扫描图

15 份 PDF（课程方案 + 14 学科，日语俄语可略），从中国政府网直接下载，**HTTP 200 全部可用**：
`bash scripts/fetch-standards.sh`

| | |
|---|---|
| 总页数 | **1,594 页** |
| 有文字层的页 | **0 页（0%）** |
| 扫描规格 | 150 DPI，JPEG/PNG 混合，522×737pt 页面 → 1088×1536px |
| 可读性 | 清晰，无倾斜无污损，多模态模型可直接识读 |

**决定性事实：官方 PDF 没有文字层，抽取绕不开图像识读。**
`pdftotext` 类工具在这里完全无效。传统 OCR 会产生截断错误——已有项目
`open-curriculum-cn` 的 `content_req` 字段有 **18% 疑似 OCR 损伤**，
例如「感悟运算之间的关」（「关系」被截断）、「单图形排列的规律,接着画。。」。

正确做法：逐页交多模态模型识读 + 结构化。1,594 页是完全可控的量。

> moe.gov.cn 的同名页面有 https→http 跳转，抓取会失败；一律走 gov.cn。

## 二、最重要的发现：抽【学业要求】，不是【内容要求】

2022 版课标每个学段下有三块：**【内容要求】/【学业要求】/【教学提示】**。

实测数学课标 p26（第一学段 数与运算）的【学业要求】原文：

> 能用数表示物体的个数或事物的顺序，**能认、读、写**万以内的数；**能说出**不同数位上的数
> 表示的数值；**能用**符号表示数的大小关系……**能熟练口算** 20 以内数的加减法和表内乘除法，
> **能口算**简单的百以内数的加减法；**能计算**两位数和三位数的加减法。

**课标的「学业要求」章节原文就已经是「能 + 可观察动词 + 对象」的句式**——
和 L0 锚点的形状天然吻合，几乎可以直接过可判定性过滤器。

而【内容要求】是章节级内容描述（「理解万以内数的意义，知道数位含义」），
抽出来只会得到章节名。`open-curriculum-cn` 抽的正是 `content_req`，
所以它 1,906 个节点的 `title` 全是「万以内数的认识」这类章节名，一条都过不了可判定性闸。

**这一条决定了整条抽取流水线的入口。**

## 四、前作全景：已有 5 个中文/他国衍生项目

Marble 发布五周，衍生项目已经出现。逐个实测过质量：

### `open-curriculum-cn`（zachsaws）— 规模最大，**不可用作底座**
1,906 概念 / 4,736 边 / 14 学科，2026-08-13 仍在推。但：

| 检查项 | 结果 |
|---|---|
| 环 | **127 条**（不是 DAG） |
| 重复边 | 296 条 |
| 年级倒挂边 | 60 条 |
| `review_status` | **1,906 / 1,906 全部 `pending`**（零人工复核） |
| 边类型 | `relates_to` 2,613 / `prerequisite` 1,759 / `progresses_to` 364 —— **过半不是先修** |
| 边来源 | `domain_logic` 2,512（「同领域」规则机器生成） |
| 边理由 | 96% 是模板，如「G7-9 同领域硬先决」——**是规则不是证据** |
| ID | **74% 内嵌年级语义**（`M_G1_NS_01`），换教材版本即失效 |
| OCR 损伤 | `content_req` 18% 疑似截断 |

**结论：不能用作底座。** 但它 OCR 出来的课标正文带 `src_page` 页码定位，
可作**交叉校验**用——我们自己识读完，拿它对一遍，不一致的地方优先复核。

### `os-taxonomy-beijing`（luw2007）— 最成熟，但路线不同
1,590 条上游翻译 + 2,008 条中国特有 + 2,619 条中国特有边，有 CI 发布闸门、
AI 共识复审、viewer。自述非常诚实：**1,586/1,590 是机器翻译未校对**，
873 条边是未审核 AI 推测。

路线是**「翻译英美体系再对齐中国课标」**，我们是**「从中国课标原生构建」**。
前者能快，但拓扑结构是 Marble 的（含它那 56 条年龄倒挂和 75 组基名冲突）。

值得注意：它独立得出了和我们一样的结论——
**「教材是课标的产生品，课标才是所有教材共同的稳定基准」**，所以只对齐课标不对齐教材。

### `cn-primary-math-knowledge-graph`（wwlwgo）— 规模最小，**方法最对**
只有 95 topics / 111 边 / 19 个能力锚点，但：

- **capability anchor** 层与教材版本解耦 —— 和我们的 L0/L2 分离是同一设计，独立收敛
- **cross-edition evidence** —— 跨教材版本定位，且显式标注 `uncertainty`
- **review_queue** 带 `communityState`，明确禁止复制教材原文/题目/OCR
- **111 条边全部 `reviewed`，且全部标 `soft`** —— 拿不到强证据就不敢断言 hard

这是目前中文圈方法论最扎实的一份。规模小得没法用，但**协议设计值得直接对齐**，
它已经在 Marble 仓提 PR 要求给 dependency 加 `reviewStatus`（#21）。

### `os-taxonomy-fr`（migueltorrezd）— 规模参照
法国国家课程，**6,051 个微主题**。这是「一个国家完整课程体系」的实测量级，
可用来校准我们 15,200 的估算（中国 K12 学科更多、学段更长，2.5 倍是合理的）。

### `os-taxonomy-japanese`（jethac）、`os-taxonomy-zh`（jinsong-y）
前者日语；后者是 Marble 的直接机翻，9.6MB，无实质加工。

## 五、检索方法的一个坑

**`gh search repos` 用中文查询基本失效**（「义务教育课程标准」「小学 生字表」等全部返回空），
`WebSearch` 是美国索引，中文教育内容覆盖很差。

有效路径：
1. 英文/拼音关键词 + `gh search`（`os-taxonomy`、`chinese-poetry`）
2. 顺着已知仓库的 issue / PR 找衍生项目（`cn-primary-math` 就是在 Marble issue #12 里出现的）
3. 政府站点用浏览器取真实链接——`WebFetch` 对 gov.cn 会读错附件 URL（实测给出的 17 个链接全部 404，真实链接带 `/zhengce/zhengceku/2022-04/21/` 路径前缀）

## 五套版式

```
物理式    1. 必修 1              → 1.1 主题名        → 【内容要求】 → 1.1.1 编号条目
化学式  （一）必修课程            → 主题 1 ：xxx      → 【内容要求】 → 1.1 小标题 → 无编号段
语文式  （一）学习任务群          → 学习任务群1 名称  → 1. 学习目标与内容 → （1）条目
外语式    表 6 语音知识内容要求    → 课程类别 内容要求 → 裸行「必修」 → 1. 条目
法语式    按级别组织，「内容要求」全文只出现 2 次      → **未适配**
```

按物理一科写完时另外 18 科全返回 0。每加一套版式都是被真实样本逼出来的。

## 比义务教育多拿到的三样

1. **官方层级编号**（`1.1.1`）。义务教育那批只有 27 条保留了编号 —— 当时的抽取提示词
   没要求过。这里编号就在文本里，白拿，而且能做**编号连续性校验**：
   `1.1.1` 之后直接是 `1.1.3` 就说明漏了一条。义务教育那批漏一条永远发现不了。
2. **课程类型**（必修 360 · 选择性必修 500 · 选修 139 · 未标 206）。
   **义务教育没有这个维度，而它对个人档案是本质区别** ——
   必修是所有学生都该有的，选修不是。不记这一维，档案里「他没掌握 X」
   就分不清是没学过还是学了没会。
3. **课标自带例题**（69 条）。比模型编的判定证据可靠。

## 版式不是一套 —— 这是这次最主要的教训

按物理一科写完，另外 **18 科全返回 0**。实测至少两套版式：

```
物理式：  1. 必修 1              →  1.1 机械运动与物理模型  →  【内容要求】  →  1.1.1 编号条目
化学式：（一）必修课程            →  主题 1 ：化学科学与实验探究 →  【内容要求】  →  1.1 小标题 → 无编号正文段
```

外加两个只有真跑才会撞上的坑：

- **全角字符**。数学等科的文字层是全角数字与拉丁字母（`Ａ类课程`、`２学分`）
  加私用区字符，ASCII 数字正则一个都匹配不上。必须先归一。
- **页眉粘在句子中间**。CID 字体抽取把页码和页眉并成一行，还在数字间插空格
  （`0 2普通高中数学课程标准 （2 0 1 7年版`）。行首锚定的正则漏掉它，
  结果页眉被并进句中：`能用描点法或借助计0 2普通高中…算工具画出具`。
  **句中污染比截断更糟 —— 截断看得出来，这个看不出来。** 改成任意位置剜除，
  773 条里剩 2 条残留。

## 已知未解决的缺陷

不推进 `anchors/` 就是因为这几条还没干净：

1. **法语完全抽不出**（第五套版式，按级别组织）；**西班牙语 21% 碎片**
   （主题列表糊成一条：`问候与告别2. 人物介绍3. 兴趣爱好`）
2. **标签粘连**：英语有 `选择性必修理解性技能1. 区分、分析…` 这类
3. **数学文字层本身是坏的**：CID 抽取在每个字之间插空格
   （`理 解 复 数 的 代 数 表 示`），且小标题会粘在条目前面
4. **一条含多要求未拆**：`理解功和功率。了解生产生活中常见机械的功率大小及其意义。`
   是两条要求。拆分是下一步，义务教育那批也走过这一步
5. **学段未定**：高中课标按模块给内容，不按年级。**不要发明年级精度** ——
   那正是 Marble「4–15 岁逐岁」的问题。真实区分在课程类型上，不在年级上

## 碎片率这个指标本身踩过一次坑

第一版把「不以句号结尾」当碎片信号，算出**生物学 100% 碎片率**——
而它其实是全表最干净的一科：`说出细胞主要由 C、H、O、N、P、S 等元素构成`
是完整的一条要求，只是课标那一栏整栏都不带句号。

**指标误判比没有指标更糟：它会让人去修没坏的东西。**
现在的判据是三个真信号：从标点/连词起头、句中夹着编号（多条糊在一起）、
混进了表头文字。改准之后整体碎片率 16% → 2%，而且 ⚠ 只剩西班牙语一科。

## 五套版式

```
物理式    1. 必修 1              → 1.1 主题名        → 【内容要求】 → 1.1.1 编号条目
化学式  （一）必修课程            → 主题 1 ：xxx      → 【内容要求】 → 1.1 小标题 → 无编号段
语文式  （一）学习任务群          → 学习任务群1 名称  → 1. 学习目标与内容 → （1）条目
外语式    表 6 语音知识内容要求    → 课程类别 内容要求 → 裸行「必修」 → 1. 条目
法语式    预备级（法语起步）→ 【学业要求】→ 1. 语言知识（…）→ 裸行子类 → N. 条目
```

按物理一科写完时另外 18 科全返回 0。每加一套版式都是被真实样本逼出来的。

## 比义务教育多拿到的三样

1. **官方层级编号**（`1.1.1`）。义务教育那批只有 27 条保留了编号 —— 当时的抽取提示词
   没要求过。这里编号就在文本里，白拿，而且能做**编号连续性校验**：
   `1.1.1` 之后直接是 `1.1.3` 就说明漏了一条。义务教育那批漏一条永远发现不了。
2. **课程类型**（必修 360 · 选择性必修 500 · 选修 139 · 未标 206）。
   **义务教育没有这个维度，而它对个人档案是本质区别** ——
   必修是所有学生都该有的，选修不是。不记这一维，档案里「他没掌握 X」
   就分不清是没学过还是学了没会。
3. **课标自带例题**（69 条）。比模型编的判定证据可靠。

## 版式不是一套 —— 这是这次最主要的教训

按物理一科写完，另外 **18 科全返回 0**。实测至少两套版式：

```
物理式：  1. 必修 1              →  1.1 机械运动与物理模型  →  【内容要求】  →  1.1.1 编号条目
化学式：（一）必修课程            →  主题 1 ：化学科学与实验探究 →  【内容要求】  →  1.1 小标题 → 无编号正文段
```

外加两个只有真跑才会撞上的坑：

- **全角字符**。数学等科的文字层是全角数字与拉丁字母（`Ａ类课程`、`２学分`）
  加私用区字符，ASCII 数字正则一个都匹配不上。必须先归一。
- **页眉粘在句子中间**。CID 字体抽取把页码和页眉并成一行，还在数字间插空格
  （`0 2普通高中数学课程标准 （2 0 1 7年版`）。行首锚定的正则漏掉它，
  结果页眉被并进句中：`能用描点法或借助计0 2普通高中…算工具画出具`。
  **句中污染比截断更糟 —— 截断看得出来，这个看不出来。** 改成任意位置剜除，
  773 条里剩 2 条残留。

## 已知未解决的缺陷

不推进 `anchors/` 就是因为这几条还没干净：

1. **西班牙语 21% 碎片**（主题列表糊成一条：`问候与告别2. 人物介绍3. 兴趣爱好`）
2. **标签粘连**：英语有 `选择性必修理解性技能1. 区分、分析…` 这类
3. **数学文字层本身是坏的**：CID 抽取在每个字之间插空格
   （`理 解 复 数 的 代 数 表 示`），且小标题会粘在条目前面
4. **一条含多要求未拆**：`理解功和功率。了解生产生活中常见机械的功率大小及其意义。`
   是两条要求。拆分是下一步，义务教育那批也走过这一步
5. **学段未定**：高中课标按模块给内容，不按年级。**不要发明年级精度** ——
   那正是 Marble「4–15 岁逐岁」的问题。真实区分在课程类型上，不在年级上

## 落库：不改写，只筛

义务教育那批栽在改写上：可判定闸要一个可判定动词，流水线就找了最省力的
「能说出 <名词> 是 <名词>」，把 93 条动手能力削成常识问答（见 [rewrite.md](rewrite.md)）。
**根因不是模型笨，是只要允许改写，就存在一条比忠实更省力的过闸路径。**

所以高中这条线的规则是：**拆句，然后只留原样就能过闸的。零模型调用，不改一个字。**
唯一的加工是给不以「能/会」开头的句子补一个「能」字前缀 —— 那是句式统一，不是改写。

```
2,266 条内容要求
  → 拆句 2,950 条（丢 2,122 条开头不完整的碎片）
  → 归一（改动 1,922 条）
  → 可判定闸 921 条（31%）
  → 去重 891 条    ← 入库
```

**31% 的过闸率是诚实的代价。** 剩下 69% 里最大一类是「无可观察行为动词」——
课标里大量是「体会…的意义」「形成…的意识」，那些本来就不该成为锚点。
硬凑就是又造一批「能说出 X」。

| 落库字段 | 值 | 为什么 |
|---|---|---|
| `stageHint` | 一律 `G10–G12` | 高中课标**按模块给内容，不按年级**。「必修 1 就是高一」是教学惯例不是课标条文 —— 发明年级精度正是 Marble「4–15 岁逐岁」的毛病 |
| `courseType` | 必修 345 · 选择性必修 274 · 选修 201 · 未标 71 | 真实区分在这一维，不在年级 |
| `track` | MATRIX 611 · DAG 280 | DAG 只给数理化，和义务教育一致 |
| `reviewStatus` | 全部 `llm-proposed` | 不是模型生成的，但**也没有任何人看过** |
| `evidence` | 优先用课标自带例题 | 比编的证据可靠 |

## 归一居然不幂等 —— 这一轮最贵的 bug

第一次落库 494 条之后 CI 报了 24 处「未规范化」。查下去发现
**`normalizeText` 单次调用不幂等**：99 条里第一遍留下尾空格、第二遍才去掉
（某个变换先 trim、后又移除了一个字符，把空格暴露出来）。

后果不只是脏数据 —— **那时已经铸了 494 个 ID**。ID 永不复用，
所以只能把整批删掉重铸。`scripts/lib/normalize-stdin.mjs` 现在跑到不动点
（上限 4 轮，不收敛就报错退出），调用方不必再关心内部顺序。

落库工具里也加了两道自检：归一前后**条数必须对齐**，归一结果**必须幂等**。
不加这两道，同样的错会在下一批数据上再犯一次。

## 碎片率这个指标本身踩过一次坑

第一版把「不以句号结尾」当碎片信号，算出**生物学 100% 碎片率**——
而它其实是全表最干净的一科：`说出细胞主要由 C、H、O、N、P、S 等元素构成`
是完整的一条要求，只是课标那一栏整栏都不带句号。

**指标误判比没有指标更糟：它会让人去修没坏的东西。**
现在的判据是三个真信号：从标点/连词起头、句中夹着编号（多条糊在一起）、
混进了表头文字。改准之后整体碎片率 16% → 2%，而且 ⚠ 只剩西班牙语一科（21%）。

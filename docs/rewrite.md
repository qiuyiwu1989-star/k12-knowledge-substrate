# 能力转写层 —— 以及一个被推翻的诊断

## 先说被推翻的那个

对比 Marble 的 `os-taxonomy` 时发现一个刺眼的差距：

```
PROCEDURAL（会做某事）   Marble 512 条  :  我们 54 条
META（学会学习）         Marble 144 条  :  我们  3 条
```

当时的诊断是：**中美课标语言不同**。NGSS 的 performance expectation 天生写成
「学生能做出 X」，而中国课标【内容要求】写成「知道 / 了解 X」；我们忠实转述课标，
就继承了它的知识本位。听起来很顺，也很像一个「体制性差异」级别的洞见。

**它是错的。** 同口径实测（`能/会` + 实做动词 vs `知道/了解/理解/认识`，
并排除「能量 / 功能 / 动能 / 技能」这类名词性的「能」）：

| | 能力动词占比 |
|---|---:|
| 义务教育课标原文（我们抽出的 963 条 `srcText`） | **64%** |
| 普通高中课标（20 科全文平均） | **64%** |

两边一模一样，而且都是能力表述占多数。**课标原文没有知识本位。**

## 真因：我们自己的抽取降级了

512 条 `KNOWLEDGE` 型锚点里，**505 条动词是「说出」**。那不是课标的语言，是一个模板。

按原文实际动词把 512 条分类：

| 原文动词 | 条数 | 占比 | 该怎么办 |
|---|---:|---:|---|
| 含**实做动词**（运用22 设计16 制作15 探究14 计算10 …） | **93** | 18% | **重抽**，我们把它降级了 |
| 含表现动词（观察15 表达14 说明12 分析7 …） | **74** | 14% | **重抽**，可无损改回 |
| 确是知识表述（知道 / 了解 / 理解 / 认识） | 135 | 26% | 改成能力形态 = 我们自己的主张，走转写层 |
| 无明确动词 | 210 | 41% | 逐条看 |

降级长什么样：

```
原文：能运用生活中的物品自制简易乐器，为歌曲伴奏或表现音乐情境。
我们：能说出自制简易乐器所使用的材料是生活中的物品
      ↑ 一条动手能力，变成了一道常识问答

原文：选择自己喜欢的玩具或制作的泥塑，尝试用数码相机、摄像设备拍摄，制作定格动画作品。
我们：能说出制作定格动画作品使用的设备是数码相机、摄像设备

原文：运用形状、色彩、空间等造型元素…欣赏、评述各国不同民族的建筑
我们：能说出形状、色彩、空间是造型元素
```

## 根因是可判定性闸自己

`scripts/lib/decidability.mjs` 要求每条断言有一个**可判定动词**——能对具体孩子答
「会 / 不会」。这道闸是对的，它砍掉了 60–70% 的口号和章节名。

但抽取流水线要过闸，而**「说出」是最省力的过闸方式**：任何一句话都能被改写成
「能说出 <某名词短语> 是 <某名词短语>」，而且必定过闸。于是闸把流水线逼向了问答题。

> **教训：硬闸会塑造流水线的行为。**
> 设计任何闸的时候都要多问一句：**过闸的最省力路径是什么，那条路径产出的东西还是我要的吗。**
> 这道闸拦住了不可判定的东西，却没拦住「可判定但被削平的东西」——
> 后者更危险，因为它长得完全合规。

## 所以顺序是：先修抽取，再谈转写

- **167 条（93 + 74）不需要转写层。** 按原文动词重抽即可，仍然是课标转述，
  「每条都能翻回教育部文件某一页」这条护城河不动。
- **只有 135 条**原文确实写「知道 / 了解」的，改成能力形态才是我们自己的教育主张，
  必须走转写层、单独标记。
- 210 条无明确动词的要逐条看，不能批量处理。

规模从「512 条都要转写」降到「135 条需要转写」。

## 转写层的六条硬闸

分层不能只是本文档里一句话——那种承诺会腐烂（见 [PROVENANCE.md](../PROVENANCE.md) 开头
那段自我记录）。六条全部由 `scripts/validate.mjs` 机器强制，`scripts/selftest.mjs`
逐条注入违规数据证明它们真的会拦：

| # | 约束 | 为什么 |
|---|---|---|
| 1 | 必须有 `provenance.derivedFrom` | 不指回源锚点，来源无从追溯 |
| 2 | `method` 不得是 `curriculum-content-rewrite` | 不许冒充课标转述 |
| 3 | **永远够不到 `auto-confirmed`** | 那一档的含义是「判定客观、根本不需要人」，而「该不该把这条知识变成这条能力」是纯教学判断 |
| 4 | 产物不得仍是 `KNOWLEDGE` 型 | 那就没转写 |
| 5 | `derivedFrom` 必须指向**活跃的 `KNOWLEDGE`** 锚点，且同学科 | 不能从能力再转能力；源弃用了转写就成孤证 |
| 6 | 有 `derivedFrom` 却不标 `capability-rewrite` 一律拦 | 防止悄悄混入 |

`manifest.json` 里 `rewrittenAnchors` 与 `curriculumDerivedAnchors` **分子分母都给** ——
说「N 条来自课标」的时候，任何人都能一眼看出其中多少不是。

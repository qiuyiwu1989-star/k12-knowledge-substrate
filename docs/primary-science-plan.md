# 小学科学：从映射工作台到应用公共底座

## 目标与当前基线
让两个不同教育应用共用一套能力 ID；每条映射能回答「具体哪个任务、关联什么能力、为什么这样判断」。

2026-09-05 基于底座 1.4 的实际筛选：科学、未弃用、可引用、学段完整位于 G1–G6，共 137 条，教师复核 0 条。
各年级投影：G1 59、G2 46、G3 78、G4 70、G5 50、G6 49。投影会重复，不能加总成总节点数。
被排除的 G1–G9 等跨学段条目保留在底座，本期不自动推荐。即使已通过机器复核，仍存在「能说出学生应……」等把教学建议转成能力的质量问题；本期没有将其悄悄改写或假装解决。

## 本次交付（005）
- 每项任务独立召回、显式确认 / 排除、手动补充能力、保存 / 载入 / 导入 / 导出。
- 明确区分 requires、trains、observes。observes 是任务设计可产生表现，尚不是学生的实际证据。
- 只读核心供 Node、HTTP、MCP 共用；复用既有词面算法和数据呈现规则。
- PostgreSQL 存应用项目；静态课标数据不写回。匿名浏览器会话隔离，非教师身份认证。
- 展示真实来源、原文/推导区别、粒度与数据指纹；不提供掌握评分。

## 下一步执行顺序

### 阶段一：把 20 个节点做准（建议 5 个工作日，教师可用后开始）
1. 从物质溶解、植物调查、工具测量三个主题选择约 20 个锚点，覆盖 G1–2、G3–4、G5–6。
2. 用 1 名小学科学教师初审，另 1 名复核有争议项。首先核对课标原文与页码，然后检查年级、粒度和教学建议误抽取。
3. 每个锚点补一张应用层能力卡：行为、情境、帮助条件、观察标准、正例、反例。能力卡以独立 ID 引用底座 anchorId，不直接替换原锚点。
4. 发现底座错误进入原有 review-queue / PR 流程；区分「引用错」「年级错」「能力描述不合适」。

产出：20 张经教师审阅的能力卡、争议列表与版本化修改建议。
验收：每张卡至少一个真实任务例子和一个不足以证明对应的反例；审阅人和结论可追踪。无教师参与时只能标草案。

### 阶段二：用两个应用检验映射（建议随后 5–7 个工作日）
1. 选一个观察/记录类应用和一个实验/制作类应用，各取至少 15 个真实任务。应用由用户确定，本计划不把示例应用当成已接入产品。
2. 教师先独立标注任务与能力关系，建立 30 条任务金标准；允许「没有合适能力」，不能强配。
3. 运行工作台召回，保留接受、排除、人工补充与理由。分别检查词面未召回、粒度过粗、相邻能力混淆、应用描述不具体。
4. 用相同 anchorId 对照两个应用，验证确实共用定义，不能仅因为术语相同就声明可迁移。

产出：两份真实应用映射包、教师金标准、错误归因报告。
建议验收门槛（预先约定，不是目前已达到）：教师目标至少 90% 进入每任务前 12 个候选；零自动确认；确认关系可全部回到任务摘录；至少 5 个节点被两个应用共同引用且经核对。
记录人工核对耗时中位数与无匹配任务比例，先取得基线再定改进目标。

### 阶段三：第三方稳定接入（在前两阶段验证后）
- 明确组织 / 应用 / 任务的身份与命名空间；用 orgId + appId + taskId 区分调用方。
- 发布单独的映射 API 版本；固定错误码、请求 ID、配额、重试和数据版本迁移规则。
- 按真实金标准比较既有词面召回、词表扩展、向量召回和模型精排。模型只从给定 ID 池中选，必须允许拒答；接外部模型前明确数据目的地和保留策略。
- 远程 MCP 使用官方 SDK、Streamable HTTP 和组织授权；复用 mapTasks，持久化工具单独授权，不能给底座写权限。
- 增加组织账户、项目成员权限、映射版本历史、审阅身份与撤回轨迹。现有浏览器会话原型不冒充多租户生产平台。

产出：一个第三方完成接入的示例、版本化契约、授权与配额测试、可回滚部署。
验收：第三方无需复制算法即可映射；旧版本调用可复现；跨组织不可读取；底座仍只读。

## 互动优化后续
1. 对照两个项目：突出共用节点、不同任务、各自的映射理由，避免只展示覆盖百分比。
2. 在能力卡上查看原文 / 推导 / 教师应用定义三层，切换时不混淆来源。
3. 收藏/保存图谱视图、按主题和年级过滤，支持键盘和移动设备。
4. 教师复核队列按实际应用中的争议频率排序，把维护精力放在真实使用的节点上。

## 后续需要的输入
- 两个实际应用的名称和各 15 个任务描述（不包含学生个人信息）。
- 可参与的科学教师及可用时间。
- 首批试点主题与年级偏好；未确定前沿用溶解、植物调查、工具测量。

## 暂不推进
学生掌握预测、统一总分、全图点亮率、跨学科自动迁移结论。先把任务映射与来源核对跑扎实。

# 中国中小学能力图谱 · 发布前审查

日期：2026-09-06。基线：1.4 / bab29ae。审查分支：audit/release-readiness-20260906。

## 结论
目前适合标明机器推导与审查边界的公开研究版，不宜把整张图描述成“全部能力和先修关系已经验证成立”。主要问题是学习行为被改写成复述要求、测量证据与能力不一致、组成关系被当成学习前置、推导身份在接口中丢失。这些问题会改变第三方应用对能力的解释，不是文字润色。

本轮未改动原始断言或依赖。修订意见作为独立提案留存；没有新增教师认证，也没有把规则未命中当作审核通过。

- 1,567 条 convention 已退出推理；当前推理图 5,128 条。
- 推理图未发现环、自环、失效端点、完全反向学段边；这些是结构检查通过，不是因果证明。

- 1,842 条推理边存在另一条可达通路。不能跨 semantic/component/instrument 类型直接做传递约简，更不能按数量一键删掉。
- 250 条推理边连接至少一个不可引用节点，其中 36 条标 hard。正式版的可信路径视图应检查端点与关系，不只过滤节点颜色。
- 6,692 条边仍标 llm-proposed，3 条 auto-confirmed；已有类型重标不等于得到独立教学证据。
- 12 条“能说出……学生应……”全部已在可引用集合。它们是高优先级语义修订候选。
- 114 条已有 independentCheck=suspect 同时处于可引用集合，需解释或重新核验该冲突。
- 511 条高中能力缺 courseType，其中 74 条可引用。不能把缺类型自动判成某年级，更不能把全部选修能力当共同毕业要求。
- 155 条源原文字段缺失全部来自 curriculum-appendix；154 条可引用。清单可以通过附录、页码和 item 链路溯源，不能机械认定全无依据。
- 315 条跨至少四年，属于粒度提醒而非内容错误；高中正常三年学段没有被此规则计入。

## 最值得先改的六类问题

### 1. 把“做事情”改成“说出别人应做什么”
例：ca_aubUqili。源片段要求展开调查并获取材料，断言却要求复述五六年级学生应做什么。这样的题即使答对，也无法证明学生会调查。

其后继转写 ca_88cN56V3 又把实际调查降为列出渠道，只覆盖规划。应该保留“规划”“获取”“整理使用”不同表现，不能用规划任务替代调查实践。

12 条同型记录全部给出了恢复学习对象的提案。若原页所在栏目是教学建议，任务应转入应用层，不能因为变得可观察就变成新增课标要求。

### 2. “断言符合原文”不能替证据不匹配免责
例：ca_UKA5QsG6 要求撰写评论，证据却是口头说出喜欢的角色、列举例子。既有裁决用断言有出处驳回了证据异议，遗漏了书面评论这一关键表现。

应分开四项结论：出处忠实度、能力构念、学段/模块、评估证据。任何一项成立都不能自动覆盖另一项。

### 3. 母子包含关系不等于必须先学后学
例：ca_VKU9hc8E / ca_d2XpK8Ar → ca_nCCmJWwZ。综合项包含搅拌和温度两个维度，可以用 AND 说明覆盖条件；这并不推出两项的教学顺序。

类似地，编创和表现、草图和三视图、听说读写、不同文体/工具，常被机械拆成 hard 前置。涉及“或、等、可选择”的源文还可能需要 OR 或情境选择，不能一律变成 AND。

### 4. 失败例子可能指向另一个能力，甚至把正确表现判错
- “会说炒的要点但不会煎炖”，被用来说明不会炒造成母项失败；错点指反了。
- “会分析长安但不会东京”，被用来证明长安前置；同样错位。
- 科学的失败说明把“只改变一个条件”当问题，反而可能否定了正确的控制变量设计。
- 英语记录把 I like to run 列为错误。该表达可合语法；若任务要求 -ing，应说“未展示指定目标形式”，不能说语言错误。[British Council 的语法说明](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2/verbs-followed-ing-or-infinitive)支持 like 后可接两种形式。

失败表征必须通过反例测试：一个具备前置能力的学生是否仍可能出现该错误？如果可能，就不能仅凭该错误反推他不会前置。

### 5. 单一任务工具不应成为广义能力的硬门槛
- 会用图表展示数据，不是“能引用证据”的普遍必要条件；可以引用文字观察记录。
- 熟练全部四则口算，不是理解加减互逆的逻辑前提；可用实物演示。
- 会唱主题，不是听辨音乐表达的必要条件。
- 独立搜集资料，不是分析已提供资料的必要条件。

把这种边改成带适用条件的支持关系；只有在明确的目标任务和工具条件下才讨论必要性。

### 6. 测量更容易，不代表测量仍然有效
“认同→说出两例”“会劳动→说出要点”“调查→列渠道”会让机器容易打分，却可能丢掉原来的构念。知识回忆可以是合法能力，不能一律删除；价值、情感、合作也不应被删除或简单压成知识题。

旧审核标准中的“某时刻会/不会”适合部分知识技能，不适合所有价值、态度与长期习惯。应保留知识、实践、解释、价值与长期表现的不同证据模型。

## 推荐的新关系模型（提案，未改数据）

1. **来源关系**：derived-from，表达课标原文与推导能力的关联。
2. **组成关系**：part-of + AND/OR/情境约束，表达综合目标由什么组成。
3. **任务内条件**：requires-within-task，限定材料、工具、支架、情境。
4. **学习支持假设**：supports-learning，记录理由与反例，不自动推断所有学生的学习次序。
5. **实证先修关系**：prerequisite-validated，需有独立任务设计与观测依据，不能由模型编写失败例直接升级。
6. **跨科同构关系**：analogous-to / shares-dimension，不和方向性先修混用。

现有 semantic/component/instrument 保留供兼容，先提供新视图与迁移映射。不同类型的边不能默认相互传递；同一孩子的档案也不能沿图自动点亮全部上游或下游。

## 深度能力拆解的落地形式

decomposition.json 给出 24 学科、96 个子表现草案，每条有原锚点、情境化任务、观察证据和不足以证明掌握的反例。所有新编号为 draft/，没有混入 ca_ 正式 ID。

以溶解探究为例：识别变量 → 控制其他条件 → 一致地记录 → 依据记录解释。这个顺序是活动过程，不是已经验证的认知发展路径。源课标“知道影响因素”、实验操作、数据证据和解释应分开存储；练过其中一项，不等于整体掌握。

## 本轮已修复的代码问题

工作台原来按文件名前缀判断推导身份。拆分后的 ca_VKU9hc8E、ca_d2XpK8Ar 不在 rewrite- 文件中，因此错误显示为课标来源。现改为共享 presenter 根据 evidenceSource 判断，HTTP / MCP / 库一致；演示快照同步规范化，并加入这两个真实 ID 与一个非转写 ID 的回归断言。7 组测试和完整 check 通过。

此修复已在审查分支，尚未发布到生产。原始 anchors/edges/ 数据逐字未变。

## 发布前执行顺序

**P0：防误导。** 修复来源显示；公开区分能力断言、推导指标、关系假设；可信路径不穿过未通过复核的端点；不能用粗线暗示可靠程度。

**P1：修构念。** 按本轮 79 条提案处理明确错位、条件丢失、母子证据复制；12 条元要求复述最先处理。争议应细分到字段，不再一条裁决抹掉全部异议。

**P2：重建关系语义。** 全量检查 3,203 条组成边及 1,626 条 hard 的适用条件，尤其 436 条仅凭“子动作”生成的记录；先建立 AND/OR/part-of 模型再考虑图简化。

**P3：补源与逐项复核。** 找回官方原 PDF，保存文档版本、文件哈希、PDF页/印刷页映射和栏目路径；先处理 114 条独立溯源疑点、252 条未审节点及高中类型缺失，随后完成剩余逐项审查。

**P4：应用验证。** 用真实应用任务验证拆解，不以节点数或覆盖率证明有效。对已明确允许 AI 复核发布的研究版，保留 AI 身份即可；不可伪造教师签字或把尚未验证的关系宣传为事实。

ID 迁移也要加强：现契约以学科/页码判断 ID 没换指向，但同一页上“背出要求”和“实际调查”已是不同能力。改变测量对象必须提供替代/迁移说明，不能只改句子而让既有应用无感继承。建议增加独立的语义变更审查，区分措辞修正和能力重定义。

# 知识库设计

## 全局

### 用「错误代价」决定信任层级，不用「模型有多确定」
强度 2｜来源：2026-08-16 · os-k12-taxonomy

同样是 AI 产出，能不能直接落盘取决于**错了会怎样**：
- 前置依赖边打错 → 推荐路径把学习者往错方向推 → 只敢标 llm-proposed
- 横切标签打错 → 最坏只是关联推荐不准 → 允许直接落盘

这条比「置信度阈值」好用得多，因为它可执行、且不依赖模型自评。

### 跨界不靠「A 是 B 的前置」表达，靠「A 和 B 练同一件事」
强度 1｜来源：2026-08-16 · os-k12-taxonomy（参考 NRC K-12 科学教育框架）

真正的跨学科前置关系罕见——判据是「学这条时必须现场用到那条别科能力」，
实测 569 条边里只有 11 条（1.9%），**那个数很可能是对的**。
硬凑只会凑出「历史分析史料 ← 语文阅读理解」这种没有具体依赖点的假边。

改用一个正交的**横切维度**（封闭词表，7 通用概念 + 8 实践）打标之后：
11 条边 → 15,127 对可查询的跨学科关联。

### 打标必须用封闭词表
强度 1｜来源：2026-08-16 · os-k12-taxonomy

开放式打标会退化成同义词泛滥，就又变回一堆没法 join 的自由文本——
而这个维度存在的全部意义就是能 join。校验器要卡死取值，模型自造的一律丢弃。

### 分档一旦被侵蚀，指标就废了
强度 3｜来源：2026-08-15 / 2026-08-16 · os-k12-taxonomy

`usable` 的含义必须始终是「能写进一个真实孩子的档案」。
- 08-15：AI 复审覆盖了已确认锚点，138 条掉到 23。**主观判断不许覆盖客观证据。**
- 08-16：用户授权「AI 先判、人有异议再改」，新开 `ai-adjudicated` 一档，
  而不是并进 `auto-confirmed`——因为**「有异议」需要有东西标着待异议才成立**。

### 规范化只能有一份实现
强度 2｜来源：2026-08-15 / 2026-08-16 · os-k12-taxonomy

Python 抽取侧一律 shell 出去调 JS 那一份（`scripts/decide.mjs`）。
照着写第二份必然漂移，然后「入库时通过、校验时被拒」会成批出现且没人说得清哪份对。

**且规范化按内容定，不按学科/前缀定。** 这条犯过两次：
先按学科豁免半角标点，后按 listId 前缀判拉丁——第二次时第一次的教训
就写在 normalize.mjs 顶部，校验器没跟上。
